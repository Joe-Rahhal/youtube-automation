# YouTube Automation

A modular Python application for generating original
educational YouTube Shorts and long-form videos.

## Current milestone

- Python application entry point
- Cloud execution using GitHub Actions
- Manual and scheduled workflow triggers

## Planned capabilities

- Topic discovery and research
- AI-assisted script generation
- Text-to-speech narration
- Licensed footage and original graphics
- Automated video editing and subtitles
- Thumbnail and metadata generation
- YouTube API uploads and scheduling
- Quality checks and publication history

## Running locally

Python 3.12 or later:

```bash
python -m src.main
```

## Cloud execution

The application runs through GitHub Actions.
No continuously running local computer is required.
